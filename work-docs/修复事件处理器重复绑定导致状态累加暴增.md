# 修复事件处理器重复绑定导致状态累加暴增

## 问题现象

点击按钮时 `age.value` 快速成倍增加（1、3、5、7、15...），每次点击增加的值越来越多。

## 根因

`patchProps` 更新事件处理器时只绑不拆，N 次更新后元素上累积了 N 个 handler，点击一次全部触发：

```
第1次 patch → addEventListener('click', handler1)
第2次 patch → addEventListener('click', handler2)   ← handler1 仍在
第3次 patch → addEventListener('click', handler3)   ← handler1+2 仍在
  ...

点击一次 → handler1(age++) + handler2(age++) + handler3(age++) + ...
         → age 每次累加 3 → 显示的增量越来越大
```

因为每次渲染都会创建一个新闭包：`onclick={() => age.value++}`，`patchProps` 比较 `oldVal !== value` 恒为 true，每次都会 `addEventListener`，旧 handler 却从未移除。

## 修复

**文件** `packages/core/src/patch.ts`

```diff
  for (const [key, value] of Object.entries(newProps)) {
    const oldVal = oldProps ? oldProps[key] : undefined
    if (oldVal !== value) {
+     // 事件处理：先移除旧 handler，再绑新 handler
+     if (key.startsWith('on') && typeof oldVal === 'function') {
+       const eventName = key.slice(2).toLowerCase()
+       el.removeEventListener(eventName, oldVal as EventListener)
+     }
      setProp(el, key, value)
    }
  }
```

`setProp` 内部不变（仍只负责 `addEventListener`），由外层 `patchProps` 负责 `removeEventListener`。旧 handler 引用保存在 `oldProps` 中，可通过 `removeEventListener` 精确解绑。

## 影响范围

所有通过 JSX 绑定的事件处理器：

```tsx
<button onclick={() => count.value++}>   // 修复后每次重新绑定
<div onmousemove={handler}>              // 同上
```

不影响非事件属性（`class`、`style`、`data-*` 等）的更新逻辑。
