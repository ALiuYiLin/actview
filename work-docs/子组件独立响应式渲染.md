# 子组件独立响应式渲染

## 问题

子组件（如 `<MyButton />`）使用自己的 `ref()` 时，ref 变化需要触发**子组件自身**的 DOM 更新，而不是重新渲染整个父组件树。

## 改动前

`render.ts` 中组件分支只是简单调用 + 递归渲染：

```ts
if (typeof vnode.type === 'function') {
  const renderFn = vnode.type(props)
  return render(renderFn())
}
```

- 没有独立的 `update()` 函数
- 子组件渲染时若访问 `ref.value`，getter 订阅的是父级的 `currentUpdateFn`
- ref 变化 → 事件总线调用父级的 `update()` → 整个父组件树重渲染

## 改动后

```ts
if (typeof vnode.type === 'function') {
  const renderFn = vnode.type(props)

  // 占位注释 → 挂载锚点
  const anchor = document.createComment('')
  let currentNodes: Node[] = []

  // 渲染并替换 anchor 后方的 DOM
  const doRender = (): Node[] => {
    currentNodes.forEach(n => n.parentNode?.removeChild(n))
    currentNodes = []

    const newDom = render(renderFn())
    const nodes = Array.isArray(newDom) ? newDom : [newDom]
    currentNodes = nodes

    if (anchor.parentNode) {
      nodes.forEach(n => anchor.parentNode!.insertBefore(n, anchor.nextSibling))
    }

    return nodes
  }

  // 子组件自己的响应式更新函数
  const update = () => {
    const prev = getCurrentUpdateFn()
    setCurrentUpdateFn(update)
    doRender()
    setCurrentUpdateFn(prev)
  }

  // 首次渲染：劫持父级上下文，让 ref 订阅子组件的 update
  const prev = getCurrentUpdateFn()
  setCurrentUpdateFn(update)
  doRender()
  setCurrentUpdateFn(prev)

  return [anchor, ...currentNodes]
}
```

## 流程图

### 首次渲染

```
外层 App.update()
  → setCurrentUpdateFn(App.update)
    → render(rootVNode)
      → render(subComponentVNode)
        ↓
76: prev = getCurrentUpdateFn()          ← prev = App.update
77: setCurrentUpdateFn(子组件.update)     ← 换人
78: doRender() → ref.value getter → 订阅 子组件.update  ← 关键
79: setCurrentUpdateFn(prev)              ← 恢复为 App.update
```

如果去掉 76-82，子组件 `ref.value` 的 getter 拿到的 `currentUpdateFn` 是 `App.update`，ref 变化会触发整个 App 重渲染。

### 后续更新

```
ref.value++
  → eventBus.publish(ref)
    → 调用 子组件.update
      ↓
72: setCurrentUpdateFn(update)    ← 设自己
73: doRender()                     ← 替换 DOM
74: setCurrentUpdateFn(prev)       ← 恢复
```

事件总线直接调 `update()`，不经过父级上下文。

## 几个设计点

| 点 | 原因 |
|----|------|
| `anchor` 注释节点 | 占位，让 `doRender` 知道往哪插新节点。不可见，不影响布局 |
| `currentNodes` 数组 | 跟踪已渲染的 DOM 节点，下次更新时先移除再重插 |
| `if (anchor.parentNode)` 检查 | `doRender` 可能在 anchor 插入 DOM 前被调用（首次渲染），跳过挂载，等父级 appendChild 时顺便把 anchor 和子节点一起插入 |
| 返回 `[anchor, ...nodes]` | 父级循环 `appendChild`，anchor 先进 DOM，后续 update 通过 anchor 定位 |
